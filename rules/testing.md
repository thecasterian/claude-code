# Testing Requirements

## Required Test Types
1. **Unit Tests** - Individual functions, utilities, classes
2. **Integration Tests** - API endpoints, database operations, service interactions

## Framework
Follow the project's own test framework. Default to GoogleTest if none exists.

## Workflow
TDD is mandatory: RED → GREEN → REFACTOR. See `tdd-workflow` skill for full steps and examples.

## Agent Support
- **tdd-guide** agent - Use PROACTIVELY for new features, bug fixes, and refactoring
